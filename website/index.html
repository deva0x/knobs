Simple on top. The whole tool underneath.

Every tool has three layers, so you never hit a wall. Start with a task, add what it doesn’t show, or open every option the tool lists.

Tasks

Everyday jobs in plain words, each with only the controls that job needs.

  • Shrink a videoMake a video file smaller, for sharing or email.
  • Convert a videoChange the format, for another app or device.
  • Trim a clipKeep only the part between two times.
  • Extract the audioSave the sound track as its own file.
  • Make a GIFTurn a short clip into an animated GIF.
  • Remove the soundKeep the picture, drop the audio.

Extra arguments

Every task has a box for anything it doesn’t show. Knobs splits the words itself, following quote rules, and never hands them to a shell.

    Try one:

    All options

    A searchable list read from the tool’s own --help. Add any tool gives you the same view for a command Knobs has never seen.

    • -ss positionStart at this time
    • -t durationStop after this long
    • -r rateSet the frame rate
    • -anDisable audio
    • -vnDisable video
    • -snDisable subtitles
    • -nNever overwrite output files

    No option matches. Try a flag like -r or a word like audio.

    A file name is just a file name.

    Knobs runs each tool directly with a list of arguments. There is no shell in between, so every value is exactly one argument, whatever characters it holds.

    my video; rm -rf ~.mov

    Typed into a shell

    A shell reads the semicolon as the end of one command and the start of another.

    1. Command 1ffmpeg -i my video
    2. Command 2rm -rf ~.mov

    Questions

    Does Knobs install the tools?

    No. Knobs runs tools you already have. When one is missing, it shows the brew install command for you to copy into Terminal, and a Check again button for when you’re done. On Linux, it names the command to install with your distribution’s package manager.

    Is it free?

    Yes. Knobs is free and open source under the MIT license. There’s no account and no subscription.

    What does it run on?

    On the Mac, macOS 26 or later with Apple Silicon; Intel Macs aren’t supported. On Linux, any desktop with GTK 4.20 or later, which means Ubuntu 26.04, Fedora 43, current Arch Linux or newer, on ARM or x86. There’s a .deb for Ubuntu, an .rpm for Fedora, and a package for Arch.

    Is it safe?

    Knobs runs each tool directly with a list of arguments, never through a shell, so an odd file name can’t start a second command. You see the exact command before you press Run. The tool still does what its arguments say, so the preview is there for you to check.

    Can I add my own tool?

    Yes. Write a JSON manifest with the tasks you want, or use Add any tool to get an options view for any command-line tool, generated from its --help.

    Why isn’t it in the Mac App Store?

    Knobs launches tools you installed with Homebrew, and the App Store sandbox doesn’t allow that. It’s a direct download instead.
